One satirical sentence for [The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) on make.fun — roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

## Entry

> The lawmakers voted to regulate AI, crypto and the internet, then called IT support because none of them could convert the bill to PDF.

## How it works

`main.ts` writes that single sentence (135 characters, one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads the file back and verifies it matches the sentence byte for byte.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-long-roast-lawmakers node main.ts
```
